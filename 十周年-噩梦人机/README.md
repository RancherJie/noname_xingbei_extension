# 十周年-噩梦人机

## 当前状态

本扩展已经完成独立加载框架，并内置当前“十周年-AI优化版”的全部AI决策逻辑。现已依据《噩梦人机强化技能表》实现37名十周年角色、共74项噩梦强化技能。

启用本扩展后，不需要同时启用“十周年-AI优化版”。若两个扩展被同时启用，二者共用相同的运行时补丁标记，已有AI优化不会被重复包裹。

## 控制权规则

噩梦强化只对当前由电脑控制的角色生效：

- 本地玩家亲自操控的角色不获得强化；
- 联机玩家操控的角色不获得强化；
- 多控模式中可被玩家操控的角色不获得强化；
- 本地玩家开启托管后，该角色按电脑角色处理；
- 玩家取消托管或接管角色后，框架会移除由本扩展添加的强化技能；
- 每个强化技能还会自动增加AI控制权过滤，避免控制权改变后继续触发。

控制权会在游戏开始、角色入场、回合切换和行动阶段开始时重新同步。

## 配置

- **启用噩梦强化技能**：关闭后只保留十周年AI优化；
- **己方电脑也获得强化**：关闭后只强化玩家的敌方AI；
- **显示噩梦强化技能**：供后续技能模块决定是否展示技能图标和说明；
- **噩梦强化等级**：预留标准、强化、极限三个档位；
- **允许噩梦AI使用隐藏信息**：默认关闭，后续技能与决策模块必须主动读取此配置才可使用隐藏信息。

## 已实现范围

- 37名原版十周年角色均已注册2项强化技能；
- 强化技能仅在角色由电脑控制时添加；
- 原角色技能文件没有被修改；需要增强原技能入口时，由本扩展在运行时进行条件式包装；
- 主动操作、费用、目标选择、伤害修正、资源上限、盖牌交换及额外行动状态均按强化表分别实现；
- 技能名称和说明已加入扩展翻译，便于在角色技能面板和日志中识别。
- 强化定义与原版角色包采用延迟初始化：即使角色包晚于扩展载入，也会在游戏开始、入场和回合切换时补注册；开局资源带有一次性标记，不会重复发放。
- 涉及伤害、治疗、形态和原技能费用的强化统一使用严格父事件匹配，避免同名事件未找到时误触发到无关结算。

## 强化技能接入接口

后续技能模块在完成 `lib.skill` 和翻译定义后，通过以下接口注册：

```js
lib.xingBeiNightmare.register("角色ID", "噩梦技能ID");

// 同一技能可绑定多个角色，也可一次注册多个技能
lib.xingBeiNightmare.register(
    ["角色ID一", "角色ID二"],
    ["噩梦技能ID一", "噩梦技能ID二"]
);
```

技能实现应通过以下接口读取运行状态：

```js
lib.xingBeiNightmare.isNightmareAi(player);
lib.xingBeiNightmare.strength();
lib.xingBeiNightmare.mayUseHiddenInformation();
lib.xingBeiNightmare.showSkills();
```

持续生效的 `mod` 效果也必须在函数内部检查 `isNightmareAi(player)`；普通触发技和主动技会由注册器自动增加控制权过滤。
