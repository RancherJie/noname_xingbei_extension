# 无名杯UI优化包

这是一个不修改无名杀核心文件的独立视觉扩展，面向无名杯对局界面。

## 当前优化范围

- 士气、星石、星杯战况面板；
- 仙侠风水晶、宝石与无方向卡背图案；
- 仙侠风角色星级、治疗槽位、治疗、黄灯与蓝灯指示；
- 仙侠风六系攻击牌、基础效果牌、魔弹、魔刃与异刃卡面；
- 红蓝双方的阵营辨识与己方高亮；
- 角色框、当前行动角色和身份标记；
- 行动按钮与技能控制栏；
- 手牌、选中牌与可选牌反馈；
- 技能选择弹窗、菜单、历史记录与文字色彩；
- 左上角系统按钮与人物点击后的技能详情、完整角色卡；
- 联机大厅房间列表、等待房席位和房间操作按钮；
- 小分辨率自适应布局；
- 可选紧凑布局、磨砂强度和轻量动效。

## 美术方向

采用仙剑式东方仙侠视觉：水墨青黛作为主色，旧宣纸负责文字与暖色层次，青玉用于交互提示，暗金铜饰勾勒边框，并以低透明云气、剑纹和玉佩意象组织装饰。红蓝只用于阵营与关键数值，不大面积铺色；保留角色原画与卡面本身，不直接使用任何官方素材。

启用或修改配置后，建议重新进入对局以确保全部界面节点刷新。
