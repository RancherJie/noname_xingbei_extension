这是一个不修改无名杀核心文件的独立视觉扩展，面向无名杯对局界面。

## 界面版本

- 原版：不加载本扩展的界面、卡面与状态图替换；
- 星空风：默认版本，使用蓝紫色星云配色、简洁星空卡背和星杯背景；
- 仙剑版：水墨青黛、旧宣纸、青玉与暗金铜饰配色；
- 水熊版：以棕色木桌、破损老羊皮桌布、厚重投影和阵营化武将边框构成的桌游主题。

界面版本切换后需要重新启动游戏。紧凑布局、磨砂强度与仙侠卡面选项仅在仙剑版和星空风生效；轻量动效开关同时控制仙剑版、星空风和水熊版的动画。扩展列表自动排序须启用本扩展，开关修改后重启生效。

## 水熊版特色

- 木桌只从破损羊皮桌布边缘露出，桌布纹理重复铺设而不拉伸；
- 木桌、羊皮纸中心和破损外框均使用独立绘制的正式位图素材，外框采用九宫格重复边缘，避免随屏幕比例直接拉伸；
- 面板、按钮和卡牌使用多层阴影、铜色细边与光泽纹理，点击时具有压下及波纹反馈；
- 五个阵营使用不同的左侧主边框：鲜血议会为血肉与眼睛，神圣教廷为银白锁链与金色十字，战技殿堂为绿色猎弓与刀刃，幻影联盟为紫色兜帽残影，咏歌城为黑洞暗星与橙色边缘火焰；
- 五种阵营边框均使用独立的透明3:4正式美术素材覆盖武将节点，不再使用CSS图形拼接徽记；
- 被动、响应、法术／启动技能具有不同颜色和运动方式的过程提示；
- 攻击属性光效垫在原攻击指示线下方，从攻击设置持续到结算结束，并按水、火、风、雷、地、光、暗系染色；攻击命中时播放对应颜色的冲击效果。

## 美术方向

仙剑版采用东方仙侠视觉：水墨青黛、旧宣纸、青玉与暗金铜饰；星空风采用蓝紫星云、亮蓝水晶与简洁星杯图案。两种主题都保留角色原画与卡面本身，不直接使用任何官方素材。

启用或修改配置后，建议重新进入对局以确保全部界面节点刷新。
